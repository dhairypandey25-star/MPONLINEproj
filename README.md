This project is a complete AI backend pipeline designed to simulate a real-world retail tech stack. It handles everything from detecting and logging customer visits using computer vision to running sentiment analysis on user feedback. It also features a built-in hybrid chatbot for answering common customer support questions. The entire system is wrapped in a production-ready FastAPI gateway, making it easy to integrate with frontend analytics dashboards or in-store camera feeds.

The platform is built using a modern Python technology stack. The backend API is powered by FastAPI and Uvicorn, ensuring high performance and automatic endpoint documentation. The machine learning components utilize OpenCV for image preprocessing and lightweight facial recognition, TensorFlow and MobileNetV2 for image classification, and scikit-learn alongside spaCy for natural language processing. The entire application is structured to be easily containerized and deployed using Docker.

To set up this project locally, you will first need to clone the repository to your machine and navigate into the main folder. You should then install all the necessary dependencies by running the package manager command to install from the requirements file. Because the application uses security headers, you will also need to configure your environment variables by setting up your designated API key. Once the environment is ready, you can start the local development server using Uvicorn to run the main application file.

Interacting with the platform is straightforward thanks to the unified REST API design. You can send POST requests to the recognize-face or classify-product endpoints by uploading images directly to the server. For text-based interactions, the sentiment analysis and chatbot endpoints accept standard JSON payloads containing the user's text message. You can easily test all of these routes and view the exact data schemas by navigating to the auto-generated Swagger documentation located at the /docs path on your local server.

When deploying this type of system in a real-world retail environment, it is crucial to consider the ethical implications of facial recognition technology. Any physical deployment must ensure strict adherence to local data privacy regulations. This includes providing clear store signage, maintaining transparency about data storage, and prioritizing customer consent before any biometric data is captured or processed for loyalty analytics.
